OracleAI Backups

Integração privada de backup que utiliza o rclone para armazenar cópias criptografadas no Google Drive do próprio usuário.

O aplicativo solicita somente a permissão drive.file: acesso aos arquivos criados ou explicitamente usados com ele. A rotina de backup será executada no servidor administrado pelo proprietário.

Este aplicativo não oferece cadastro público nem é um serviço de armazenamento para terceiros.
